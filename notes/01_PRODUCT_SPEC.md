## 1. 서비스 개요

**LOOMA**는 본인과 가족, 지인, 반려동물의 **질병과 증상을 꾸준히 기록하고 관리**하는 모바일 앱입니다.

기존 건강 기록 앱이 "혈압을 적는다", "체중을 적는다" 같은 **숫자 중심의 단편 기록**에 머물러 있다면, LOOMA는 **"말로 편하게 털어놓으면 AI가 정리해주는 방식"** 으로 접근합니다.

> 슬로건: **"꾸준히 기록하며 회복 흐름을 만들어요"**

이 앱의 기록 단위는 **"루틴"** 입니다. "엄마의 고혈압", "내 역류성 식도염", "반려견 관절염"처럼 **관리하고 싶은 대상 × 질병**을 하나의 루틴으로 만들고, 그 루틴에 **매일의 상태를 음성이나 텍스트로 기록**합니다. 기록한 내용은 AI가 주요 증상, 투약 기록, 컨디션 등 **카테고리별로 자동 정리**해서 한눈에 볼 수 있는 기록지로 만들어줍니다.

운영 주체는 **LOOMA** 이며, 현재는 **MVP 단계** 로 핵심 기능에 집중하고 있습니다.

## 2. 사용자 유형

MVP 단계에서는 아래 세 유형의 사용자를 우선 고려합니다.

**① 본인 건강 관리자**
자신의 만성 질환이나 반복되는 증상(역류성 식도염, 편두통, 불면증 등)을 꾸준히 관찰하고 싶은 사람. 병원 방문 시 의사에게 보여줄 기록을 만들고 싶어합니다.

**② 가족 케어러 (Caregiver)**
부모님의 고혈압, 당뇨, 자녀의 아토피·알러지 등 **가족의 건강을 대신 관리**하는 사람. 보통 30~50대 자녀 세대이며, 본인 기록과 가족 기록을 한 앱에서 함께 관리하고 싶어합니다.

**③ 다중 대상 관리자**
본인 + 부모님 + 배우자 + 반려동물 등 **여러 대상의 여러 질병**을 동시에 관리해야 하는 사람. 기록지별로 흐름을 나눠서 보고 싶어합니다.

공통점은 "기록은 하고 싶은데, **매일 길게 적을 여유가 없는 사람들**"입니다.

## 3. 핵심 문제 정의

이 앱이 해결하려는 문제는 기능 문제가 아니라 **꾸준함의 문제** 입니다.

**문제 1. 건강 기록은 3일을 못 간다**
기존 앱들은 입력할 항목이 너무 많습니다. 혈압, 체중, 복약, 식사, 수면을 각각 다른 화면에서 입력해야 하고, 그마저도 숫자나 체크박스로만 받습니다. "오늘 속이 불편했다"는 말을 입력할 곳이 없습니다.

**문제 2. 여러 사람의 건강을 한 곳에서 관리할 곳이 없다**
부모님 혈압은 수첩에, 아이 증상은 카톡 메모에, 내 복약은 머릿속에 있습니다. 흩어진 기록은 흐름을 만들지 못합니다.

**문제 3. 병원에 갈 때 보여줄 요약이 없다**
"지난 2주간 어떠셨어요?"라는 질문에 대답할 재료가 없습니다. 기억에 의존하게 되고, 중요한 패턴을 놓칩니다.

**LOOMA의 접근**
- **말하기 편한 대로 녹음**: 정리된 문장일 필요 없음. 중언부언 쏟아내도 AI가 알아서 일목요연하게 정리.
- **루틴 단위 관리**: 질병별로 기록 흐름을 분리해서 쌓음.
- **AI 자동 정리**: 말한 내용을 카테고리별로 정리해 **재방문했을 때 읽기 쉬운 기록지**로 만듦.

## 4. 주요 기능 영역

MVP는 아래 다섯 개 기능 영역으로 구성됩니다.

### ① 간편 로그인
카카오 OAuth 하나로 가입과 로그인이 완료됩니다. 이메일·비밀번호는 사용하지 않습니다. 건강 데이터는 민감정보이므로, 약관 동의 단계에서 "민감정보 수집 및 이용"에 별도 필수 동의를 받습니다.

### ② 기록 루틴 관리
"누구의 어떤 질병"을 하나의 루틴으로 만들어 관리합니다. 루틴 하나 = 질병 하나가 원칙입니다. 같은 사람이어도 질병이 다르면 루틴도 별도로 만듭니다.

- 기록 대상: 본인 / 부모님 / 배우자 / 자녀 / 친구 / 기타(직접 입력 — 반려동물, 조부모 등)
- 대상별 기본 정보: 성별, 생년월일, 키, 체중
- 기록지 제목: 질병명 또는 증상명 (예: "역류성 식도염")

루틴은 생성 후 루틴명 변경, 삭제가 가능합니다. 루틴을 삭제해도 **과거에 쌓인 기록은 남습니다.**

### ③ 음성·텍스트 기반 일일 기록
하루 중 언제든 루틴에 들어가 오늘의 상태를 기록합니다. 입력 방식은 두 가지입니다.

- **음성**: 마이크 버튼을 누르고 편하게 말하면 텍스트로 변환됩니다.
- **텍스트**: 직접 타이핑합니다.

변환된 텍스트는 유저가 **전송 전에 직접 수정할 수 있습니다.** STT가 완벽하지 않을 수 있다는 전제하에 마지막 교정 기회를 제공합니다.

### ④ AI 기록지 자동 생성
유저가 입력한 내용을 AI가 읽고, 사전에 정의된 카테고리(주요 증상 / 투약 기록 / 운동 / 수면 등) 중 **해당되는 것만 골라서** 카테고리별 카드로 정리해줍니다. 유저는 정리된 기록지를 확인하고, 필요하면 **어떤 내용이든 수정하거나 삭제하거나 새 카테고리를 추가**할 수 있습니다.

### ⑤ 날짜별 기록 조회
홈 화면에서 날짜를 바꾸거나 캘린더를 열어 과거 기록을 조회할 수 있습니다. 캘린더에서는 기록이 있는 날짜가 시각적으로 표시됩니다.

## 5. 주요 화면 그룹

앱 전체 화면은 크게 다섯 개 그룹으로 묶입니다.

**A. 온보딩/인증 그룹**
스플래시, 카카오 로그인, 약관 동의, 닉네임 입력, 가입 완료 화면이 여기에 속합니다. 처음 한 번만 거치는 흐름입니다.

**B. 루틴 생성 그룹**
홈에서 "루틴 추가"를 눌렀을 때 진입하는 3단계 온보딩입니다. 기록 대상 선택 → 대상 기본정보 입력 → 질병/증상 입력 → 완료 순서로 진행됩니다.

**C. 홈 그룹 (매일 보는 화면)**
앱 사용의 90%가 이뤄지는 곳입니다. 상단에 날짜와 캘린더, 중앙에 오늘의 기록 영역과 기록 루틴 영역이 있습니다. 오늘 기록한 카드가 위에 쌓이고, 아래에는 언제든 눌러서 기록을 시작할 수 있는 루틴 목록이 있습니다.

**D. 기록 작성/수정 그룹**
이 앱의 심장부입니다. 음성 또는 텍스트로 기록을 시작하고, AI 분석 결과를 확인하고, 필요하면 수정하는 모든 화면이 여기에 포함됩니다.

**E. 마이페이지 그룹**
프로필 정보 수정, 알림 설정, 로그아웃, 회원 탈퇴 같은 계정 관리 화면입니다. 홈 탭 옆 "내 정보" 탭으로 진입합니다.

## 6. 핵심 사용자 시나리오

아래는 대표 사용자의 실제 사용 모습입니다.

### 시나리오 ①: "엄마 고혈압 기록 시작하기" (신규 유저 첫날)

차차 씨(38세)는 최근 어머니의 혈압이 불안정해져 병원에 모시고 다닙니다. 매번 "최근에 어떠셨어요?"라는 질문에 막연하게 답하는 게 답답해서 LOOMA를 설치합니다.

1. 앱을 열고 카카오로 로그인, 약관에 동의하고 닉네임 "차차"를 입력합니다.
2. 홈 화면에 "아직 오늘 기록이 없어요"가 뜹니다. "+ 루틴 추가"를 누릅니다.
3. "누구의 질병을 기록할까요?"에서 **부모님**을 선택합니다.
4. 어머니의 기본 정보(여성, 1958년생, 158cm, 60kg)를 입력합니다.
5. "무엇을 기록해 볼까요?"에 **"엄마 고혈압"** 을 적고 다음을 누릅니다.
6. "기록 루틴을 만들었어요" 화면이 뜨고, 홈으로 돌아가니 방금 만든 루틴이 보입니다.

### 시나리오 ②: "오늘의 기록 남기기" (매일 반복)

차차 씨는 저녁에 어머니 댁에 들른 뒤 집에 돌아와 침대에 눕습니다. 앱을 켭니다.

1. 홈 화면에서 "엄마 고혈압" 루틴의 **오늘의 기록 시작하기**를 누릅니다.
2. 마이크를 누르고 편하게 쏟아냅니다. "오늘 엄마 집에 가니까 혈압이 좀 높게 나왔어요, 아 145에 92였고, 두통도 좀 있으시대요 그래서 혈압약은 저녁에 드렸고, 아침에는 산책 한 30분 하셨다고 하셨어요."
3. 변환된 텍스트를 확인합니다. "92"가 "9도"로 잘못 변환된 걸 보고 직접 수정합니다.
4. 전송 버튼을 누릅니다. "열심히 요약하는 중..." 이라는 로딩이 뜹니다.
5. 잠시 후 기록지가 생성됩니다. **주요 증상**에 "두통 약간", **투약 기록**에 "저녁 혈압약 복용", **운동**에 "아침 산책 30분", **컨디션**에 "혈압 145/92" 가 정리되어 있습니다.
6. **[기록 완료]** 를 누릅니다. "오늘의 기록을 완료했어요" 화면에서 **[홈으로]** 를 누릅니다.
7. 홈 화면 상단 "오늘의 기록"에 방금 만든 카드가 보입니다.

### 시나리오 ③: "기록 수정하기"

잠들기 전, 차차 씨는 어머니가 낮에 "무릎도 아프다"고 말씀하셨던 게 생각났습니다.

1. 홈에서 오늘의 기록 카드를 눌러 기록지 상세로 갑니다.
2. **[추가하기]** 를 누르고, 항목명에 "기타 증상"을 입력합니다.
3. 내용에 "오후에 왼쪽 무릎 약간 시큰함"을 입력하고 저장합니다.
4. 기록지에 새 카드가 추가된 걸 확인한 뒤 **[저장하기]** 를 누릅니다.

### 시나리오 ④: "병원 갈 때 지난 기록 보기"

2주 뒤, 차차 씨는 어머니를 모시고 내과에 갑니다.

1. 대기실에서 앱을 엽니다. 홈 화면 상단의 **캘린더** 를 펼칩니다.
2. 지난 2주간 파란 점이 찍힌 날짜들이 보입니다. 며칠씩 빠진 날도 있지만 대부분 기록이 있습니다.
3. 날짜를 하나씩 눌러 그날의 기록지를 의사 선생님께 보여드립니다.

## 7. 데이터 흐름 개요

유저가 "말 한 번" 하고 나서, 화면에 정리된 기록지가 뜨기까지 내부에서 일어나는 일을 **비개발자 관점** 으로 풀어 설명합니다.

```
① 유저가 음성으로 말함
     ↓
② 앱이 녹음 파일을 OpenAI Whisper API로 보냄
     ↓
③ Whisper가 음성을 텍스트로 변환해서 돌려줌
     ↓
④ 유저가 텍스트 확인 후 필요시 수정
     ↓
⑤ 확정된 텍스트를 Anthropic Claude API로 보냄
     ↓
⑥ Claude가 사전에 정의된 카테고리 세트 기반으로
   "주요 증상 / 투약 기록 / 운동 / ..." 같은 카드 형태로 정리해서 돌려줌
     ↓
⑦ 정리된 결과를 MongoDB에 저장 (민감정보이므로 암호화)
     ↓
⑧ 화면에 기록지 카드 표시
```

텍스트로 입력하는 경우는 ①~③ 단계를 건너뛰고 곧바로 ⑤로 진행됩니다.

AI 호출 과정은 **LangSmith**로 추적합니다. 응답 시간, 성공/실패율, 프롬프트와 응답 내용을 모두 기록해서 품질을 모니터링합니다.

## 8. STT / AI가 들어가는 위치

이 앱에서 AI 기술은 **두 개의 명확한 지점**에만 들어갑니다. 기능이 여기저기 퍼져있지 않고, 한 흐름 안에서만 동작합니다.

### ● STT (OpenAI Whisper API)
기록 작성 화면에서 유저가 **마이크 버튼을 눌러 음성을 녹음한 뒤 중지했을 때** 동작합니다. 녹음된 음성 파일을 Whisper API로 보내 텍스트로 변환합니다. 변환 결과는 화면에 바로 표시되고, 유저가 직접 수정할 수 있습니다.

> 📝 MVP에서는 **"중지 후 일괄 변환"** 방식으로 진행합니다. 녹음 중 실시간으로 보이는 텍스트 느낌은 **시각적 피드백(움직이는 점이나 파형 등)** 으로 대체합니다. 실제 실시간 스트리밍 STT는 향후 확장 고려 사항입니다.

### ● AI 분석 (Anthropic Claude API)
유저가 확정한 텍스트를 Claude에게 보내고, **카테고리별 기록지 JSON** 형태로 받아옵니다. Claude는 다음 규칙으로 동작합니다.

- 운영자가 사전에 정의한 카테고리 마스터 리스트(약 20개 예정) 중에서만 선택합니다.
- 어느 카테고리에도 딱 맞지 않는 내용은 **"기타" 카테고리에 분류**합니다. (내용이 누락되지 않도록 보장)
- 각 카테고리별로 **불릿 리스트** 형태의 간결한 내용을 생성합니다.

Claude 프롬프트와 카테고리 마스터 리스트는 별도 문서(`04_AI_PROMPTS.md`, 추후 작성)에서 정의됩니다.

### ● AI가 들어가지 않는 곳
혼동을 피하기 위해 명시합니다. MVP 단계에서 다음은 **AI를 사용하지 않습니다.**

- 주간/월간 요약지 (향후 확장)
- 기록 리마인더/푸시 알림 (향후 확장)
- 개인화된 건강 조언/진단 (제공하지 않음 — 의료 조언 회피)

## 9. 향후 확장 기능

MVP 이후 단계적으로 검토할 기능들입니다. **현재는 개발하지 않습니다.**

### 단기 확장 (MVP 출시 직후)
- **주간/월간 AI 요약지**: 일정 기간의 기록을 모아 "이번 주 엄마 혈압은 평균 어떠했고, 어떤 패턴이 보인다"는 식의 요약 리포트 생성.
- **기록 리마인더 알림**: 하루의 특정 시간에 "오늘 기록 하셨나요?" 푸시 발송.
- **1:1 문의**: 현재는 버튼만 있고 연결 없음. 초기에는 **구글폼 링크**로 대체 가능.

### 중기 확장
- **실시간 STT 스트리밍**: 말하는 동안 텍스트가 실시간으로 보이도록 개선.
- **중복 기록 UX 개선**: 같은 루틴을 하루에 여러 번 기록할 때 "추가할지 / 새로 만들지" 선택 UX.
- **대상별 맞춤 입력 필드**: 반려동물 선택 시 기본정보 필드가 달라지는 것 등.
- **병원 공유용 PDF/이미지 내보내기**: 기록지를 병원에 보여주기 좋은 형태로 export.

### 장기 확장
- **건강 패턴 인사이트**: "혈압 수치가 높았던 날은 수면이 부족했던 날과 겹칩니다" 같은 AI 기반 인사이트.
- **가족 간 공유**: 배우자·형제가 같은 부모님 기록을 함께 보거나 기록할 수 있는 공동 관리.
- **의료진 공유 링크**: 기록지를 의사에게 공유할 수 있는 뷰 링크 기능.
