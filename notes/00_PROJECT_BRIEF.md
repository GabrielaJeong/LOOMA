# 00_PROJECT_BRIEF

## 1. 서비스 한 줄 설명

**말하거나 적기만 하면, AI가 나와 가족의 건강 기록을 매일 정리해주는 앱**

---

## 2. 해결하려는 문제

건강은 매일 챙겨야 하지만, 실제로 꾸준히 기록하는 사람은 드뭅니다. 특히 다음과 같은 문제가 있습니다.

- 건강 기록 앱은 **입력이 번거로워서** 며칠 쓰다가 포기하게 됩니다.
- 부모님이나 아이 등 **가족의 건강 상태를 한곳에 모아 관리**할 방법이 거의 없습니다.
- 병원에 가거나 가족과 이야기할 때, **지난 몇 주간의 상태를 한눈에 보여줄 요약**이 없습니다.
- 혈압, 복약, 컨디션, 수면 같은 기록이 **여기저기 흩어져 있어** 흐름을 파악하기 어렵습니다.

이 서비스는 "말 한마디면 끝나는 기록"과 "AI가 알아서 만들어주는 요약지"로 이 문제를 해결합니다.

---

## 3. 핵심 사용자

가장 먼저 타겟하는 사용자는 다음과 같습니다.

- **30~50대 자녀 세대**: 부모님 건강을 챙기면서 본인 건강도 관리하고 싶은 사람
- **만성질환 관리자**: 혈압, 혈당, 복약 등 매일 기록이 필요한 사람
- **영유아·노부모 보호자**: 가족 구성원의 컨디션을 대신 기록하고 관리하는 사람

공통점은 **"기록은 하고 싶은데, 매일 길게 쓸 시간은 없는 사람들"** 입니다.

---

## 4. 핵심 기능 (MVP)

MVP 단계에서는 아래 4가지 기능에만 집중합니다.

1. **카카오 로그인 & 가족 프로필 관리**
   - 카카오 계정으로 빠르게 로그인
   - 본인 외에 가족 구성원(부모님, 자녀 등)을 추가해 함께 관리

2. **음성 & 텍스트 건강 기록**
   - 말로 기록(음성 → Whisper로 텍스트 변환) 또는 직접 타이핑
   - 증상, 복약, 혈압, 수면 등 자유롭게 기록 가능

3. **AI 자동 정리 & 일일 요약**
   - Claude가 기록을 읽고 카테고리별(증상/복약/컨디션 등)로 자동 정리
   - 하루 단위 요약 카드를 생성

4. **기간별 건강 요약지**
   - 주간/월간 단위로 AI가 건강 흐름을 요약한 "요약지" 생성
   - 병원 방문이나 가족 공유에 바로 쓸 수 있는 형태

---

## 5. 핵심 반복 사용 흐름 (Daily Flow)

이 앱에서 사용자가 **매일 반복하는 흐름**은 단 하나입니다. 이 흐름이 쉽고 빠르게 돌아가는 것이 서비스의 성패를 가릅니다.

```
[앱 열기]
   ↓
[기록할 사람 선택] (나 / 엄마 / 아이 등)
   ↓
[녹음 버튼 누르고 말하기] 또는 [텍스트 입력]
   예) "오늘 아침 혈압 130에 85, 두통 약간 있었고 혈압약 먹음"
   ↓
[Whisper가 음성을 텍스트로 변환]
   ↓
[Claude가 기록을 카테고리별로 정리]
   → 혈압: 130/85
   → 증상: 두통(약함)
   → 복약: 혈압약 복용
   ↓
[오늘의 기록 카드 저장 완료]
   ↓
(주/월 단위로 AI가 요약지를 자동 생성)
```

**목표 체감 시간: 기록 시작부터 저장까지 30초 이내**

## 6. 현재 상태

- ✅ **전체 서비스 목업 완성** (화면 플로우, UI 모두 확정)
- ⏳ **개발 착수 전** (프론트/백엔드 코드 아직 없음)
- 🎯 **다음 단계**: 바이브코딩 방식으로 MVP 개발 시작

개발은 "완벽한 구조"보다 **"끝까지 동작하는 흐름"** 을 먼저 만드는 것을 우선합니다.

## 7. 기술 스택 요약

| 구분 | 사용 기술 | 역할 |
|------|----------|------|
| Frontend | Next.js 14 (App Router), React 18 | 사용자 화면 |
| Backend | Node.js, Express | API 서버 |
| Database | MongoDB + Mongoose | 사용자/기록 데이터 저장 |
| 로그인 | Kakao OAuth 2.0 + JWT | 간편 로그인 & 인증 |
| 음성 인식 | OpenAI Whisper API | 말한 내용을 텍스트로 변환 |
| AI 분석 | Anthropic Claude API | 기록 정리 & 요약지 생성 |
| LLM 모니터링 | LangSmith | AI 호출 품질/비용 추적 |
| 보안 | AES-256 암호화, HTTPS | 건강 정보 보호 |
