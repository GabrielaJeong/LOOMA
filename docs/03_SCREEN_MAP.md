## 🔌 주요 API 엔드포인트 (미리보기)

실제 스펙은 바이브코딩 시 `routes/` + Zod 스키마로 정의.

```
POST   /auth/kakao              카카오 OAuth 콜백
POST   /auth/logout
POST   /users/signup            닉네임 포함 가입 확정
GET    /users/me
PATCH  /users/me
PATCH  /users/me/notifications
DELETE /users/me                (soft delete)

GET    /routines
POST   /routines
PATCH  /routines/:id
DELETE /routines/:id            (soft delete)

GET    /records?date=YYYY-MM-DD
GET    /records/:id
GET    /records/calendar?month=YYYY-MM  캘린더 점 표시용
POST   /records                 AI 분석 + 저장을 한 번에
PATCH  /records/:id
DELETE /records/:id             (hard delete)

POST   /stt/transcribe          Whisper 호출 래퍼
```
